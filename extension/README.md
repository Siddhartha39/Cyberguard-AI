# CyberGuard AI - Chrome Extension (Manifest V3)

## Real-Time Phishing Threat Shield & Website Security Posture Auditor

### How to Install in Google Chrome, Brave, or Edge:

1. Open your browser and navigate to:
   ```
   chrome://extensions
   ```
2. Enable **"Developer mode"** (toggle in the top-right corner).
3. Click **"Load unpacked"** (button in top-left).
4. Select the `extension` folder inside this project directory (`/Users/siddhartha/Desktop/aad/projects/cyberAI/extension`).
5. Pin the **CyberGuard AI** shield icon to your browser toolbar!

Whenever you navigate to any website, CyberGuard will automatically evaluate its risk in the background and display real-time security alerts.
